Security Demo

Front-end only demonstration. Account data and lockout state live in localStorage and can be inspected or changed by anyone using this browser. This is not production authentication.

What this demonstrates

  • PBKDF2 with SHA-256, a random per-account salt and 150,000 iterations; the plain password is not stored.
  • Generic sign-in failure messages, three-attempt lockout, and a visible 30-second countdown.
  • A two-minute inactivity timeout with a 15-second warning.
  • Reviews are rendered with textContent, so entered markup is displayed as text.
